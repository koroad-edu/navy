해군 장병 교통안전 교육 — 모바일 앱(PWA) 배포 안내
======================================================

[ 이 폴더 구성 ]
  index.html                     ← 교육 앱 본체(모두 내장)
  manifest.webmanifest           ← 앱 정보(설치형)
  sw.js                          ← 오프라인/설치 지원(서비스 워커)
  icon-192.png / 512 / 180 ...   ← 앱 아이콘
  구글시트_연동_AppsScript.gs      ← 결과 자동수집용(선택)
  videos/  (직접 추가)            ← 로컬 영상 사용 시 mp4를 여기에

------------------------------------------------------
1. GitHub Pages 로 배포 (예전 방식과 동일)
------------------------------------------------------
  1) GitHub에서 새 저장소(repository) 생성 (Public).
  2) 이 폴더의 파일 전부를 저장소에 업로드(끌어다 놓기).
     - 영상을 로컬로 쓸 경우 videos 폴더도 함께 업로드
       (단일 파일 100MB 이하 / 필요 시 720p·H.264로 압축).
  3) 저장소 [Settings] > [Pages]
       · Source: Deploy from a branch
       · Branch: main / (root) 선택 후 Save
  4) 잠시 후 생성되는 주소가 앱 URL:
       https://<본인계정>.github.io/<저장소이름>/
  5) 이 URL을 장병에게 배포(문자/카톡/QR).
     휴대폰 브라우저로 열고 "홈 화면에 추가" 하면 앱처럼 실행됨
     (앱 안의 '📲 홈 화면에 앱으로 추가' 버튼 또는 브라우저 메뉴 이용).

  ※ QR코드는 네이버/구글 'QR 생성'에 위 URL을 넣으면 즉시 만들 수 있음.
  ※ 콘텐츠(문항·영상)를 수정하면 sw.js 의 CACHE 버전(v1→v2)을 올려야
    사용자 기기에서 새 내용으로 갱신됨.

------------------------------------------------------
2. 영상 넣기 (index.html 상단 VIDEOS 설정)
------------------------------------------------------
  로컬:   l1: { type:"file",    src:"videos/01_음주운전.mp4" }
  유튜브: l2: { type:"youtube", id:"영상ID" }
  없음:   l4: null

------------------------------------------------------
3. 결과 자동수집 (구글시트 '해군' 탭) — 선택
------------------------------------------------------
  · 개인 휴대폰으로 분산 수강 시 결과를 한 곳에 모으려면 필요.
  · 구글시트_연동_AppsScript.gs 파일의 설치 순서를 따른 뒤,
    발급된 웹앱 URL을 index.html 의 SHEET_ENDPOINT 에 붙여넣기.
  · 미설정 시에는 각 기기(localStorage)에만 기록되며,
    앱 하단 '관리자'(비밀번호 koroad)에서 CSV로 내려받을 수 있음.
